
# Student Performance Predictor

## Project Overview
Student Performance Predictor is a Machine Learning project that predicts student exam scores based on academic factors.

## Features
- Student dataset generation
- Data analysis and preprocessing
- Random Forest Regression
- Model evaluation using MAE and R2 Score
- Actual vs Predicted visualization
- Feature importance visualization
- Interactive student score prediction
- Streamlit web application

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Seaborn
- Plotly
- Streamlit

## Machine Learning Algorithm
Random Forest Regressor

## Model Evaluation
- MAE: 4.72
- R2 Score: 0.82
